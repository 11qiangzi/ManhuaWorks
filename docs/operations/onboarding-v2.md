# 新手指引 v2：工坊流程 5 步走通第一集

> **作者**：陈远枢（运营总监）
> **日期**：2026-06-08
> **版本**：v2.0（覆盖 `onboarding.md`）
> **配套**：W3 工坊（Studio）新版界面
> **目标**：让 100% 内测用户在 30 分钟内完成第一集漫剧

## 1. 概述

W3 阶段的工坊（Studio）采用**5 步向导**替代 W2 的"自由探索"模式。每一步都有明确产出物和"完成"判定，确保用户**不会卡住**。

**5 步流程**：
1. **创建项目** → 命名 + 选类型
2. **导入剧本** → 上传 / 粘贴 / 选模板
3. **剧本拆分** → LLM 自动拆为分镜
4. **风格设定** → 选艺术风格 + 角色参考
5. **一键生成** → 排队 + 实时进度

**成功标准**：
- 30 分钟内完成
- 产出 1 集（90-180 秒）漫剧
- 用户对流程评分 ≥ 4.5/5

## 2. 5 步流程总览

```mermaid
stateDiagram-v2
    [*] --> 创建项目: 登录后引导
    创建项目 --> 导入剧本: 跳过/完成
    导入剧本 --> 剧本拆分: 自动跳转
    剧本拆分 --> 风格设定: 拆分成功
    风格设定 --> 一键生成: 配置完成
    一键生成 --> [*]: 第一集完成

    创建项目 --> 退出: 取消
    导入剧本 --> 退出: 取消
    剧本拆分 --> 修改剧本: 不满意
    修改剧本 --> 剧本拆分: 重新拆
    风格设定 --> 剧本拆分: 返回修改
```

**关键设计**：
- ✅ 任何一步都可"上一步"修改
- ✅ 进度条常驻顶部，可跳转已完成步骤
- ✅ 关键步骤有"示例视频"和"模板库"
- ❌ 不强制顺序：老用户可跳过向导进自由模式

### 6.2 视觉风格（30+ 预设）

| 类别 | 风格示例 |
|:--|:--|

```

... (30 个)
[自定义风格 ⭐]  →  上传参考图 + 文字描述
```

### 6.3 角色立绘

**智能识别**：从剧本中自动识别角色名（如"林启"、"陈雪"），列出 5-8 个待设计角色。

**生成方式**：
- **方式 A：AI 自动生成**（推荐）
  - 输入：角色名 + 剧本描述 + 选定风格
  - 输出：4 张候选立绘 → 用户选 1 张
- **方式 B：手动上传**
  - 上传用户已画好的角色图
- **方式 C：参考图模式**
  - 上传参考图，AI 生成相似风格

**角色一致性**：
- 一旦选定，立绘作为后续所有镜头中该角色的"参考图"
- 支持手动"修正"：在某一镜头不满意时，标注后系统重新生成该镜头的角色

### 6.4 配音音色

| 音色 ID | 描述 | 适用 |
|:--|:--|:--|
| `male_young_01` | 青年男声 | 少年主角 |
| `male_mature_01` | 成熟男声 | 中年角色 |
| `male_narrator_01` | 磁性男声 | 旁白 |
| `female_young_01` | 少女声 | 女主 |
| `female_mature_01` | 御姐声 | 女强 |
| `child_01` | 童声 | 儿童角色 |
| `robot_01` | 电子音 | AI/系统 |

**自动分配**（可改）：
- 旁白：男声
- 主角：根据性别自动匹配
- 配角：复用同性别主音色

## 9. 异常处理总表

| 错误 | 触发条件 | 用户提示 | 系统动作 |
|:--|:--|:--|:--|
| 剧本为空 | 用户粘贴 0 字 | "请粘贴至少 100 字" | 阻止下一步 |
| 剧本超长 | 超过 50,000 字 | "建议分段上传" | 截断提示 |

| 余额不足 | 积分 < 600 | "余额不足，请充值或领取新人礼包" | 跳转充值页 |
| 任务超时 | > 2 小时 | "生成超时，可联系客服" | 自动退款 |
| 用户中途关闭 | 关闭浏览器 | - | 任务后台继续，3 天有效 |
