## 1. 北极星指标

**NSM = 月活创作者数（MAU-Creator）**

定义：过去 30 天内，至少创建 1 个项目 OR 完成 1 集漫剧 的去重用户数。

**为什么是它**：
- 直接反映产品价值
- 关联所有其它指标
- 长期可累积

**目标**：
- W2 内测结束：50 人
- 2026 Q3：500 人
- 2026 Q4：2,000 人
- 2027 Q1：10,000 人

## 2. AARRR 漏斗

### Acquisition（获客）

| 指标 | 定义 | 目标 | 当前 |
|:--|:--|:--|:--|
| **注册数** | 日新增注册 | 内测期 5/日 | - |

**关键监控**：

### Activation（激活）

| 指标 | 定义 | 目标 | 当前 |

| **DAU/注册** | 30 日内 DAU / 注册 | > 30% | - |

**关键监控**：
- 引导漏斗每一步的流失
- 首集生成成功率

### Retention（留存）

| 指标 | 定义 | 目标 | 当前 |

**关键监控**：

## 5. 漏斗看板

### 5.1 注册 → 激活漏斗

```
落地页访问    100%     ← 监控：跳出率
  ↓
注册          30%      ← 监控：注册转化率
  ↓
完成偏好      85%      ← 监控：偏好完成率
  ↓
粘贴文本      75%      ← 监控：引导流失
  ↓
启动生成      90%      ← 监控：操作流失
  ↓
完成第 1 集   85%      ← 监控：技术失败率
  ↓
分享/导出     60%      ← 监控：价值感知
```

**总漏斗转化**：30% × 85% × 75% × 90% × 85% × 60% = **9.8%**

> 优化目标：每一步提升 5%，总体转化率能到 15%。

### 5.2 免费 → 付费漏斗

```
免费用户      100%     ← 监控：免费配额用完率
  ↓
触发付费墙    40%      ← 用完免费配额
  ↓
进入付费页    60%      ← 看到套餐
  ↓
选择套餐      80%      ← 选具体套餐
  ↓
完成支付      70%      ← 支付成功
  ↓
成为付费      -        ← 13.4% 转化
```

**总转化**：13.4%

## 7. 数据采集

### 7.1 事件埋点

| 事件 | 触发时机 | 关键属性 |
|:--|:--|:--|
| `signup_completed` | 注册成功 | source, channel |
| `onboarding_step_completed` | 引导步骤完成 | step_no, duration |
| `project_created` | 项目创建 | template, style |
| `workflow_started` | 工作流启动 | template_id, episode_no |
| `workflow_step_completed` | 步骤完成 | step_no, duration, cost |
| `workflow_completed` | 全部完成 | total_cost, total_duration |
| `workflow_failed` | 失败 | failed_step, error_code |
| `export_completed` | 导出完成 | platform, format |
| `share_clicked` | 分享 | platform, channel |
| `payment_completed` | 付费 | plan, amount |
| `key_added` | BYOK | provider |
| `feedback_submitted` | 反馈 | type, score |

### 7.2 工具栈

| 用途 | 工具 |
|:--|:--|
| 事件采集 | 自研（基于 PostgreSQL + Kafka）|
| 行为分析 | PostHog（自托管）|
| 业务 BI | Metabase |
| 错误监控 | Sentry |
| 性能监控 | Prometheus + Grafana |
| 客服数据 | Intercom / 飞书机器人 |
| 财务数据 | 自研 + 飞书表格 |

### 7.3 隐私合规

- 用户 ID 加密存储
- IP 截断（前 3 段）
- 30 天后聚合化
- 欧盟用户支持 GDPR 删除
