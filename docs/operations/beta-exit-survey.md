## 1. 概述

### 1.1 退出问卷目的

| 维度 | 说明 |
|:--|:--|
| **产品改进** | 收集真实用户声音，迭代产品 |
| **流失分析** | 了解流失用户的真实原因 |
| **续费决策** | 评估付费/不付费的影响因素 |
| **公测准备** | 为公测提供数据支撑 |
| **案例素材** | 收集证言 + 改进点 |

### 1.2 问卷时长

- 完整问卷：15 分钟
- 简短问卷：5 分钟（流失用户使用）

### 1.3 激励

| 完成度 | 激励 |
|:--|:--|
| 完整 10 题 | ¥30 代金券 + 2,000 积分 |
| 简短 5 题 | ¥10 代金券 + 500 积分 |

| 分数 | 类型 | 占比预期 |
