## 5. 申请表单设计

**问卷链接**：`forms.manhuaworks.com/beta-apply`

**字段**（10 题，预计 5 分钟）：

1. **基本信息**
   - 姓名
   - 微信号
   - 邮箱
   - 飞书 ID（如有）

2. **职业背景**
   - 您的身份？（网文作者/短视频/MCN/出版社/其他）
   - 您所在公司/工作室
   - 您的粉丝数或作品量级

3. **内容生产现状**
   - 您目前每月生产多少集视频？
   - 单集制作成本大约？
   - 您最头疼的环节是？

4. **对 ManhuaWorks 的期待**
   - 您最想用我们做哪类内容？
   - 您预期我们能帮您节省多少成本/时间？
   - 您愿意试多久才给反馈？

5. **使用能力**
   - 您用过哪些 AI 工具？（剪映/即梦/Sora/Runway……）
   - 您有 API Key 吗？
   - 您有自己的技术团队吗？

6. **时间承诺**
   - 7 月份您每周能投入多少时间？
   - 您是否愿意每周提交 1 次反馈？

7. **展示许可**
   - 是否同意我们将您的案例脱敏后展示？
   - 是否愿意录制 60 秒使用感受视频？

8. **联系方式偏好**
   - 飞书群 / 微信群 / 邮件

9. **其它建议**
   - 您对我们的产品有什么建议？

## 6. 筛选标准

**入选权重**：

| 维度 | 权重 | 说明 |
|:--|:--|:--|
| 身份匹配度 | 30% | 网文/短视频/MCN 优先 |
| 内容生产量 | 25% | 每月 ≥ 3 集优先 |
| 粉丝量/影响力 | 15% | 有助于案例传播 |
| 反馈意愿 | 20% | 时间承诺 + 沟通能力 |
| 多样性 | 10% | 5 大类型用户都有 |

**筛选流程**：
1. 收到申请 → 自动打分（基于问卷）
2. 60 分以上 → 进入面试（飞书 15 分钟视频）
3. 面试通过 → 发送入选通知 + 邀请入群
4. 7 月 1 日统一启动

**淘汰机制**：
- 启动后 7 天未使用 → 提醒
- 14 天仍未使用 → 取消资格，候补递补
