## 6. 单位经济模型（LTV/CAC）

### 单位用户经济（专业版）

**获客成本（CAC）**：
- 渠道：飞书、知乎、抖音、小红书
- 平均：¥80/人

**月费收入（ARPU）**：¥149
**毛利润率**：70%（成本占 30%）

**LTV 计算**：
- 月留存：85%
- 平均生命周期：1 / (1 - 0.85) = 6.7 个月
- LTV = ¥149 × 6.7 × 0.70 = ¥699

**LTV / CAC 比**：699 / 80 = 8.7（健康区间 3-5）

> **结论**：当前模型下，专业版用户的 LTV/CAC 远超健康线，可以加大获客投入。

## 7. 实时成本计算器（前端）

用户在定价页看到的交互式计算器：

```typescript
// 简化版计算逻辑
function calculateCost(episodes: number, quality: 'standard' | 'high') {
  const costPerEpisode = quality === 'standard' ? 6.78 : 34.10;
  const platformCost = costPerEpisode * 1.3;
  const byokCost = costPerEpisode * 1.005; // 通道费

  return {
    platform: episodes * platformCost,
    byok: episodes * byokCost,
    saving: episodes * (platformCost - byokCost),
    savingPercent: ((platformCost - byokCost) / platformCost * 100).toFixed(1)
  };
}
```
