> 从"6 个散装 app + 走过场的流程",升级为——
> **「3 站一体 + 一条内容产线 + 一个用户创作体系」的工业化 AI 创作平台。**

**三条线的分工:**
| 线 | 内容 | 状态 |

| A. 内容产线 | 漫剧流程 v2.2(七阶段+三闸门+费控) | ✅ 方案已定 |

## 二、平台架构(采纳 v3.0,合并修订)

### 2.1 三站结构(6站 → 3站)

```
① 主站 :3000     公开首页+登录+6大创作模块+内容产线(v2.2)
   = web + studio + user创作部分      → 获客 + 创作主阵地
② 客户后台 :5180  工作台+项目+素材+作品+团队+API+通知+开发者文档
   = user-portal + dev-portal         → 用户的"管理驾驶舱"
③ 管理后台 :5174  运营+用户管理+计费+审计+合规+监控+服务+设置
   = admin-portal + ops-portal        → 平台方的"作战室"
```

### 2.2 清理与复用
- 废弃合并:`studio`→主站;`ops-portal`→管理后台;`dev-portal`→客户后台;
- 后端 12 微服务**架构保留**,新增/强化:任务中心 API、成本遥测、创作档案服务。

## 三、后台重构(管理后台 · 作战室四区)

> 从"看板集合"升级为"运营作战室"——每个区回答一个问题:用户怎么样?内容行不行?钱赚不赚?系统稳不稳?

### A. 用户运营区(回答:用户怎么样?)
- 用户列表 + 分层画像(注册/试用/付费/流失)+ 生命周期时间轴
- 运营操作:封禁 / 认证 / **配额调整** / 客服工单 / 定向通知
- 转化漏斗:注册→首次生成→付费→续费(每步转化率)

### B. 内容与质量区(回答:内容行不行?)
- 项目/作品审计 + 审核队列(合规)
- **创作档案查看**(提示词/参数/批次——法律证据链,只读)
- AI 内容标识记录(隐式标识写入日志)

### C. 商业区(回答:钱赚不赚?)
- 套餐/订单/退款/发票/BYOK 账单
- **成本利润看板**(新增·关键):每单成本(对接费控遥测)→ 毛利实时可见
- 异常告警:单集成本超线/亏损订单

### D. 系统区(回答:系统稳不稳?)
- 12 服务监控 + 日志审计 + 告警
- **模型服务管理**:供应商/密钥/配额/熔断开关(一键切供应商!)

## 四、用户端管理(重新策划 · 五大体系)

> 定位升级:用户端不是一个"登录+项目管理",而是 **"创作操作系统"** ——
> 用户从"进来做一集"到"持续经营一个账号/IP"的全生命周期支撑。

### 体系 1:账号体系(个人创作者为主 · ✅已拍板)
- 登录:微信 + 邮箱;2FA(已有 user-service 基础)
- 个人中心:资料 / 安全 / 消息 / 偏好设置
- 支持个人**多项目并行**(一个人可同时经营多个 IP 账号)
- 团队/席位/MCN 功能:**本期不做**(不做预留设计,保持架构轻)

### 体系 2:套餐与配额
- 四档:免费 / 基础 ¥39 / 专业 ¥149 / 企业定制(对齐研讨会 P0-2)
- **计量统一为"次"**(前端"集"→后端"次"映射)
- **双轨付费(✅已拍板)**:(a)**平台套餐**——含积分,按次扣,无需自备密钥;（b)**BYOK**——用户自备密钥(火山等),平台只收工具费/基础订阅;模型成本用户自担、平台毛利更稳
- 配额看板:本月用量/剩余/预估花费(用户可见——**透明即信任**)

### 体系 3:资产中台(降本关键!)
- 项目 / 角色库 / 场景库 / 素材 / 音色 / **风格卡**
- **跨项目跨集复用**:第二集起角色/场景直接调用 → 成本与工期断崖下降
- 资产生命周期:草稿→可用→归档;带版本

### 体系 4:任务中心(⚡AI 产品的心脏)
- 所有生成任务统一队列:排队/运行/成功/失败/重试
- 每任务显示:**进度、花费、返修轮次**(对接费控遥测)
- 失败自动重试≤N 次;超限转人工;可取消
- **用户再也不会"点了生成不知道跑哪了"**

### 体系 5:作品与发布
- 作品库(成片/封面/字幕/工程归档)
- **发布提示卡**:导出时附"合规提示"(提醒用户在各平台主动做 AI 显式标识)
- 发布去向由用户自理(平台不追踪——✅已拍板)
- **发布联动只到"导出 + 提示卡"**(不做数据回填——✅已拍板)

**支撑体系**:通知(站内信+微信模板消息)、帮助中心、新手引导、模板库(题材模板)。

## 六、实施路线(三线并行 · 四阶段)

> 在研讨会 28 天计划基础上扩展;原则:**止血优先、产线并跑、用户端与后台随行**。

| 阶段 | 时间 | 平台线(B/C) | 产线线(A) |
|---|---|---|---|
| **T0 止血** | ~1 周 | P0:认证统一 / 计费对齐 / 设计系统约束 | P0:第一集真链路(带费控) |
| **T1 合并** | 1~2 周 | P1:3站架构合并 + 任务中心 v1 + 成本遥测 | 第一集成片复盘、成本基线 |
| **T2 体系** | 2~3 周 | P2:编辑器整合 + **用户端五大体系**(配额/资产/任务/作品) + 后台四区改造 | 第二~三集(模板化) |
| **T3 上线** | ~1 周 | P3 功能完善 + P4 打磨部署 + 合规内置(告知书/AI标识) | 连续 3 集合格率≥90% |

每阶段延续研讨会的**验收制**(清单化+销号制)。
