从两个技能文件中提取 mockup 设计依据:

## 二、品牌色系统

### 2.1 主色板

```
品牌主色: 深海军蓝 (#1A2E5A)
  → ad-designer: "deep navy" descriptor, 用于主按钮/导航/强调
  → ad-creative: 品牌页面一致性

品牌强调色: 暖琥珀 (#F5A623)
  → ad-designer: "warm amber" descriptor, 用于 CTA/高亮
  → ad-creative: CTA 按钮醒目

品牌背景: 暖米白 (#FAF7F2)
  → ad-designer: "off-white" descriptor, 用于卡片/大底色
  → ad-creative: 减少视觉疲劳
```

### 2.2 功能色（admin/ops 专用）

```css
/* 数据仪表板语义色 — admin/ops 核心需求 */
```

## 三、字体系统（admin/ops 专用）

### 3.1 中文字体栈

```css
--font-admin-heading: 'PingFang SC', 'Microsoft YaHei', 'Noto Sans SC', sans-serif;
--font-admin-body: 'PingFang SC', 'Microsoft YaHei', 'Hiragino Sans GB', sans-serif;
--font-admin-mono: 'JetBrains Mono', 'SF Mono', 'Consolas', 'Courier New', monospace;
--font-admin-data: 'DIN', 'JetBrains Mono', 'SF Mono', monospace;  /* 数字专用 */
```

### 3.2 字号梯度

| Token | 大小 | 用途 | 来源 |
|-------|------|------|------|
| `text-2xs` | 10px | 图表轴标签、脚注、数据微标 | — |
| `text-xs` | 12px | 表格内容、标签、副文本 | ad-creative Platform Specs (最小可见) |
| `text-sm` | 14px | 表单、按钮、卡片描述 | ad-creative Meta 推荐字号 |
| `text-base` | 16px | 正文字、表格标题 | ad-creative 正文基准 |
| `text-lg` | 18px | 卡片标题、区段标题 | — |
| `text-xl` | 20px | Modal 标题、侧栏标题 | — |
| `text-2xl` | 24px | 页面标题 | — |
| `text-3xl` | 30px | 仪表板 KPI 数字 | 大数字冲击力 |
| `text-4xl` | 36px | 登录页/品牌展示 | ad-designer hero visual |

### 3.3 字重

```
--font-light:    300;   /* 大数字、KPI */
--font-normal:   400;   /* 正文 */
--font-medium:   500;   /* 按钮、标签 */
--font-semibold: 600;   /* 卡片标题、表头 */
--font-bold:     700;   /* 页面标题 */
```

> 来源: ad-designer Brand Bible "bold geometric sans" → admin 用中型 sans, 数据用 mono

## 四、布局风格

### 4.1 布局哲学

```
"Minimal and clean, whitespace-heavy"
  → ad-designer Brand Bible §Layout Pattern
  → admin/ops 数据密集，更需要留白来制造呼吸感
```
