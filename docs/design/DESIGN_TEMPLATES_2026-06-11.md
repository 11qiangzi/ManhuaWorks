# 设计模板标准化规范

> 编制: 陆流光 (设计) | 日期: 2026-06-11 | 依据: ad-designer + ad-creative 双技能
> 覆盖: Banner / 落地页 / 海报 3 大类

---

## 一、模板设计原则（从技能提取）

### 1.1 构图公式（ad-designer Step 3 — 8 字段 Prompt 公式）

```
[SUBJECT]    — 焦点元素 (谁/什么)
[SETTING]    — 环境/背景
[MOOD]       — 情绪传达
[COMPOSITION]— 构图/景别
[LIGHTING]   — 光线质量/方向
[COLOR]      — 2-3 色 (从品牌圣经)
[STYLE]      — 摄影/插画风格
[AVOID]      — 排除项
```

**模板设计时逐字段对照** — 不要跳过任何字段。5 字段的 prompt 往往比 8 字段更强 (ad-designer 原话)。

### 1.2 变体策略（ad-creative §Angles — 3-5 个不同角度）

一个模板不是一张图。每个模板至少产出 3 个变体:

| 变体角度 | 文案策略 | 视觉差异 |
|---------|---------|---------|
| 痛点型 | "别再手动 X" | 问题场景图 |
| 结果型 | "3 天达成 Y" | 成功画面 |
| 好奇型 | "顶级公司都在用的秘密" | 悬念构图 |
| 社交证明型 | "10,000+ 团队的选择" | 人群/logo 墙 |
| 紧迫型 | "限时免费" | 倒计时/红色强调 |

### 1.3 尺寸矩阵（ad-designer Step 4 — Aspect Ratio）

| 比例 | 像素 | 适用场景 |
|------|------|---------|
| `1:1` | 1080×1080 | 社媒信息流 (Instagram/Meta Feed) |
| `9:16` | 1080×1920 | 竖屏故事/视频 (Stories/Reels/TikTok) |
| `16:9` | 1920×1080 | 横屏封面/横幅 (YouTube/LinkedIn Cover) |
| `4:5` | 1080×1350 | Meta Feed (更高屏占比) |

## 二、Banner 横幅模板

### 2.1 模板定义

```
BANNER = 静态横幅广告图
来源: ad-designer 5 步流程 (collect → brand bible → prompt → aspect ratio → generate)
```

### 2.2 核心规范

| 属性 | 规范 |
|------|------|
| 画布 | 4 种比例全支持 (1:1 / 9:16 / 16:9 / 4:5) |
| 文案位置 | 视觉重心偏移侧 (三分法) —— 不在画面正中心堆字 |
| 品牌元素 | 不出现 logo 于 AI 生成层 (ad-designer Rule 2), logo 叠加于后期 |
| CTA 位置 | 右下/底部, 与视觉流终点对齐 |
| 安全区 | 四周 5% 边距, 关键元素不入裁剪区 |

### 2.3 模板变体

#### Banner-A: 产品 Hero
```
┌──────────────────────────────────────┐
│  [大背景氛围图, 16:9]                 │
│                                      │
│                   HEADLINE           │
│                   ≤30 字             │
│                                      │
│                   subtext ≤50 字     │
│                              [CTA]   │
└──────────────────────────────────────┘
构图: 黄金分割, 文案在右 1/3
风格: 品牌色氛围光 + 产品剪影
来源: ad-designer Example (waking up woman → 构图公式)
```

#### Banner-B: 文案主导
```
┌──────────────────────────────────────┐
│  BIG BOLD HEADLINE                   │
│  大字冲击, ≤15 字                    │
│                                      │
│  副标题支撑                          │
│                                      │
│  [CTA BUTTON]                        │
│                                      │
│  (背景: 品牌色渐变 + 纹理)            │
└──────────────────────────────────────┘
构图: 居中, 文字权重 70%
风格: typography-first
来源: ad-creative §Headlines That Click (短冲击力)
```

#### Banner-C: 社交证明型
```
┌──────────────────────────────────────┐
│  [LOGO WALL]  [LOGO] [LOGO] [LOGO]   │
│                                      │
│  "10,000+ 团队选择我们"              │
│  "4.9 ★ | 好评率 98%"               │
│                              [CTA]   │
└──────────────────────────────────────┘
构图: logo 墙在上, 文案中部
来源: ad-creative §Angles → Social Proof
```

### 2.4 Banner 文案规范（ad-creative 平台限制）

| 平台 | 标题上限 | 描述上限 | CTA 上限 |
|------|---------|---------|---------|
| Google RSA | 30 字符 | 90 字符 | — |
| Meta Feed | 40 字符 | 30 字符 | — |
| LinkedIn | 70 字符 | 100 字符 | — |
| TikTok | — | 80 字符 | — |
| **Banner 内部** | **≤30 字(中文)** | **≤50 字** | **≤12 字** |

> 来源: ad-creative §Platform Specs, 内部标准取最严约束

## 三、落地页模板

### 3.1 模板定义

```
LANDING PAGE = 广告点击后的目标页面
来源: ad-creative (landing page 文案承接) + ad-designer (视觉品牌一致性)
```

### 3.2 落地页铁律（ad-creative §Writing Quality + Common Mistakes）

1. **兑现承诺**: 广告标题说了什么，落地页首屏必须能看见 (不 clickbait)
2. **品牌一致**: 颜色/字体/风格 = 广告素材 (ad-designer brand bible)
3. **视觉层级**: Hero → 价值主张 → 社交证明 → CTA (F 型阅读)
4. **移动优先**: 首屏 75% 空间给视觉, CTA 在拇指区 (底部)

### 3.3 模板变体

#### LP-A: 产品注册型
```
┌──────────────────────────────────────────┐
│  [HERO SECTION]                          │
│  ┌────────────────────────────────────┐  │
│  │  大标题 ≤25 字                     │  │
│  │  副标题 ≤50 字 描述核心价值         │  │
│  │                                    │  │
│  │  [EMAIL INPUT] [立即注册 CTA]      │  │
│  │  无需信用卡 · 永久免费              │  │ ← objection handling
│  └────────────────────────────────────┘  │
│                                          │
│  [SOCIAL PROOF]                          │
│  ┌────────────────────────────────────┐  │
│  │  已服务 10,000+ 团队                │  │
│  │  ★ 4.9 | "用了就回不去" — 某客户   │  │
│  └────────────────────────────────────┘  │
│                                          │
│  [FEATURES 3-COL]  功能亮点三栏          │
│  [FINAL CTA]        最后号召              │
│  [FOOTER]           链接/合规             │
└──────────────────────────────────────────┘
```

#### LP-B: 内容下载型 (Lead Magnet)
```
┌──────────────────────────────────────────┐
│  [HERO — 封面图/电子书 mockup]            │
│  标题: "免费下载: X 行业 2026 白皮书"     │
│                                          │
│  左侧: [FORM]                            │
│    姓名 / 公司 / 邮箱 / [立即下载]        │
│                                          │
│  右侧: [BULLETS]                         │
│    ✓ 50 页深度分析                       │
│    ✓ 含 20+ 案例研究                     │
│    ✓ 可编辑模板附赠                      │
│                                          │
│  [TRUST BAR] 被 XXX/XXX/XXX 引用          │
└──────────────────────────────────────────┘
```

#### LP-C: 电商促销型
```
┌──────────────────────────────────────────┐
│  [HERO — 产品大图/视频, 16:9]             │
│                                          │
│  ⚡ 限时优惠 | 还剩 2 天                  │ ← urgency
│  产品名                                  │
│  ¥199  ¥399  [立即购买]                  │ ← 划线价
│                                          │
│  [SCARCITY] "仅剩 47 件" 进度条 ████░░    │
│  [REVIEWS]  用户评价轮播                  │
│  [FAQ]      常见问题                      │
│  [CTA]      底部固定购买按钮              │
└──────────────────────────────────────────┘
```

### 3.4 落地页文案规范

| 层级 | 元素 | 规范 | 来源 |
|------|------|------|------|
| H1 | 主标题 | ≤25 字, 动词+利益 | ad-creative §Headlines |
| H2 | 副标题 | ≤50 字, 支持 H1 | ad-creative §Descriptions |
| CTA | 行动按钮 | ≤12 字, 具体动词 | ad-creative §CTA |
| Trust | 社交证明 | 数字+品牌名+星级 | ad-creative §Angles: Social Proof |
| FAQ | 异议处理 | "无需信用卡" "免费试用" | ad-creative §Descriptions: handle objections |

## 四、海报模板

### 4.1 模板定义

```
POSTER = 静态宣传海报 (印刷/数字)
来源: ad-designer 品牌视觉 + ad-creative 角度策略
```

### 4.2 海报与 Banner 的本质区别

| 维度 | Banner | Poster |
|------|--------|--------|
| 交互 | 可点击 → 必须挂 CTA | 纯看 → CTA 可选 |
| 信息密度 | 低 (钩子+CTA) | 中高 (主题+详情) |
| 视觉权重 | 图 60% + 文 40% | 图 50% + 文 50% |
| 生命周期 | 短 (Campaign 周期) | 长 (活动周期/品牌) |
| 尺寸 | 平台限定 | 自由 (A4/A3/自定义) |

### 4.3 模板变体

#### Poster-A: 活动宣传
```
┌──────────────────────────────────────────┐
│  [大型视觉 — 全幅出血]                    │
│                                          │
│  ┌────────────────────────────────────┐  │
│  │       活动主题 (大字, 品牌色)        │  │
│  │       日期 · 地点 · 嘉宾            │  │
│  │                                    │  │
│  │          [扫码报名]                 │  │
│  └────────────────────────────────────┘  │
│                                          │
│  底部: 主办方 + logo (后期叠加)           │
└──────────────────────────────────────────┘
比例: 9:16 (竖版) 或 3:4 (A 系列)
风格: 品牌色氛围 + 留白呼吸感
```

#### Poster-B: 产品发布
```
┌──────────────────────────────────────────┐
│  [产品大图 — 居中, 暗色背景]              │
│                                          │
│  新产品名                                 │
│  一句话卖点                               │
│                                          │
│  三大亮点:                                │
│  ┌─────┐  ┌─────┐  ┌─────┐             │
│  │ 特征1│  │ 特征2│  │ 特征3│             │
│  └─────┘  └─────┘  └─────┘             │
│                                          │
│  上市日期 · 官网                           │
└──────────────────────────────────────────┘
比例: 2:3 或 A3
构图: 对称, 产品居中, 特征三栏
```

#### Poster-C: 品牌形象
```
┌──────────────────────────────────────────┐
│                                          │
│         [极简构图]                        │
│                                          │
│      一句品牌主张                          │
│      ≤15 字                              │
│                                          │
│      brand-name (小字, 右下)              │
│                                          │
└──────────────────────────────────────────┘
比例: 1:1 或 3:2
构图: 大面积留白, 视觉焦点在中心
风格: editorial / minimal photography
来源: ad-designer §Brand Bible (Imagery Style + Layout Pattern)
```

## 五、设计系统整合

### 5.1 三模板共用的视觉语言

```yaml
# 从 ad-designer Brand Bible 6 字段提取
visual_system:
  primary_color:
    descriptor: "深海军蓝"         # 不写品牌名, 用描述词
    hex_hint: "#1A2E5A"
    usage: "主按钮/标题/强调元素"

  accent_color:
    descriptor: "暖琥珀色"
    hex_hint: "#F5A623"
    usage: "CTA/高亮/装饰线"

  background:
    descriptor: "暖米白"
    hex_hint: "#FAF7F2"
    usage: "卡片背景/大面积底色"

  typography:
    heading: "bold geometric sans-serif"
    body: "clean sans-serif, 16px, 1.5 leading"
    mood: "modern, confident, approachable"

  imagery:
    type: "暖调 editorial photography"
    grading: "warm, slight desaturation, lifted blacks"
    no_no: "不冷色调, 不过度饱和, 不杂乱背景"

  layout:
    pattern: "minimal and clean, whitespace-heavy"
    density: "留白 > 填充, 视觉呼吸感"
```

### 5.2 三模板对照表

| 维度 | Banner | 落地页 | 海报 |
|------|--------|--------|------|
| 目的 | 点击 | 转化 | 认知 |
| 文案量 | 少 (≤80 字) | 中 (≤500 字) | 中 (≤200 字) |
| CTA | 必须有 | 必须有 | 可选 |
| 视觉重心 | 图 > 文 | 文 > 图 (首屏) | 图 = 文 |
| 交付格式 | PNG (1K draft → 4K final) | HTML/CSS | PNG/PDF |
| 迭代频率 | 高 (campaign 级) | 中 (季度级) | 低 (品牌级) |
| 字符限制来源 | ad-creative Platform Specs | ad-creative §Descriptions | 无 (印刷自由) |

## 六、交付标准

### 6.1 文件结构

```
design/
├── banner/
│   ├── 2026-06-11-banner-<项目>-draft.png       ← 1K 草稿 (ad-designer Step 5)
│   ├── 2026-06-11-banner-<项目>-final.png       ← 4K 终稿
│   └── briefs/
│       └── banner-<项目>.json                   ← creative brief 输入
├── landing-page/
│   ├── lp-<项目>.html
│   └── assets/
└── poster/
    ├── 2026-06-11-poster-<项目>-draft.png
    └── 2026-06-11-poster-<项目>-final.png
```

### 6.2 每模板交付前自检 (ad-designer §Self-Review)

| # | 检查项 | Banner | 落地页 | 海报 |
|---|--------|--------|--------|------|
| 1 | 文案准确无误 | ✓ | ✓ | ✓ |
| 2 | 无幻觉 logo (AI 生成层) | ✓ | N/A | ✓ |
| 3 | 尺寸/比例正确 | ✓ | ✓ | ✓ |
| 4 | 品牌色对齐 | ✓ | ✓ | ✓ |
| 5 | CTA 清晰可操作 | ✓ | ✓ | 可选 |
| 6 | 移动端可用 | ✓ | ✓ | — |
| 7 | 整体质量过关 | ✓ | ✓ | ✓ |

### 6.3 迭代流程

```
ad-creative 角度策略
       ↓
   creative brief ← 输入
       ↓
ad-designer prompt 构建
       ↓
  1K draft → self-review → 迭代 (≤3 次)
       ↓
  用户审批
       ↓
  4K final → 交付
```

---

> **本规范从 ad-designer (v1) 的 5 步生成流程 + 7 项自检和 ad-creative (v1.1.0) 的平台规范 + 角度策略 + 写作标准中系统提取。**
> 三个模板的核心差异化在 "文案量 × CTA 必要性 × 迭代频率", 共享同一套品牌视觉语言。
