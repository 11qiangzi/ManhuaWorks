## 路由设计

```typescript
// 单仓库多 app 的路由
app.mhwork.cn/                    → 用户后台
app.mhwork.cn/studio              → 创作者工作台（独立子域）
app.mhwork.cn/portal/             → 门户首页

ops.mhwork.cn/                    → 业务总后台
ops.mhwork.cn/dashboard           → 数据看板
ops.mhwork.cn/users               → 用户管理

admin.mhwork.cn/                  → 平台总后台
admin.mhwork.cn/monitor           → 系统监控
admin.mhwork.cn/services          → 服务列表

dev.mhwork.cn/                    → 开发者后台
dev.mhwork.cn/docs                → API 文档
dev.mhwork.cn/keys                → API Keys
```

**单点登录（SSO）**：
- 4 个子域共享 `auth.mhwork.cn` 域名下的 cookie
- 一个账号登录，4 个后台无缝切换
- 退出时清除所有子域的 session
