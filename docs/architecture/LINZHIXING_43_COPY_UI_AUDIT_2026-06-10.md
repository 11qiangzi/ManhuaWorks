## 六、全局性问题 (跨 5 前端)

### 文案全局问题

| 优先级 | 问题 | 影响 | 建议 |
|--------|------|------|------|
| P0 | **无统一术语表** | "项目" 可能叫 Project, "分镜" 可能叫 Shot/Frame/Storyboard, 用户困惑 | 建立 `packages/shared/i18n/glossary.json` 统一术语 |
| P0 | **5 前端无 i18n 框架** | 中英文混杂, 无切换能力 | vue-i18n 统一集成, 默认中文 |
| P1 | **错误提示文案不统一** | 同一错误在不同前端显示不同文案 | `packages/shared/i18n/errors.json` |
| P2 | **无多语言计划** | 国际化为时尚早, 但架构预留 | vue-i18n lazy load locale files |

### 排版全局问题

| 优先级 | 问题 | 影响 | 建议 |
|--------|------|------|------|
| P0 | **无设计系统 (Design System)** | 5 前端字号/间距/圆角/阴影各自为政 | 建立 `packages/shared/design-tokens` CSS 变量 |
| P0 | **字体不统一** | web 用 Inter, studio 用系统字体, portal 可能用默认 | 统一字体栈: `'PingFang SC', 'Microsoft YaHei', sans-serif` |
| P1 | **无响应式断点规范** | 各站自行定义 breakpoint | 统一: sm=640, md=768, lg=1024, xl=1280, 2xl=1536 |
| P1 | **间距系统不一致** | margin/padding 无统一 scale | 统一 spacing: 4/8/12/16/20/24/32/40/48/64px |
| P2 | **无网格系统** | 各站自定列数 | 统一 12 列 grid, gutter 24px |

### UI 全局问题

| 优先级 | 问题 | 影响 | 建议 |
|--------|------|------|------|
| P0 | **无统一组件库** | Button/Input/Modal/Table 每站自己写, UI 不一致 | 提取 20+ 共享组件到 `packages/shared/ui` |
| P0 | **无主题系统** | 深色/浅色无法切换 | CSS 变量 + vueuse useDark |
| P0 | **品牌色不统一** | 可能各站用了不同主题色 | 主色 #7C3AED / 辅色 #06B6D4 / 背景深 #0F0F23 / 背景浅 #F8FAFC |
| P1 | **无图标库统一** | 可能混用 Heroicons/Lucide/自定义 SVG | 统一 Lucide (Vue 3 生态最好) |
| P1 | **无过渡动画规范** | hover/click/enter 动画时长/easing 不一致 | 统一: hover 0.2s ease, enter 0.3s ease-out, leave 0.2s ease-in |
| P2 | **无无障碍 (a11y) 规范** | 可能缺少 aria-label/focus-visible/keyboard nav | WCAG 2.1 AA 最低标准 |
