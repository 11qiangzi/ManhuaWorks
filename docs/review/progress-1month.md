##八、关键学习

###做得好的（Wins）

1. **微服务架构清晰**：8 个服务边界明确，独立部署
2. **AI 工作流顺畅**：ComfyUI +自研调度，效率高
3. **文档同步产出**：技术文档与代码同步，避免后期补
4. **Demo优先**：每周都有 Demo，迭代快
5. **代码评审到位**：所有 PR 都经过评审，质量高

###需要改进（Lessons）

1. **需求变更频繁**：W3改了3 次PRD，影响排期
2. **测试人手不足**：测试只有1 人（兼），后期补
3. **数据看板延期**：数据组人手不够，需调整
4. **移动端未规划**：早该在 W2规划，错过窗口
5. **第三方依赖**：某些 API选型未充分评估
