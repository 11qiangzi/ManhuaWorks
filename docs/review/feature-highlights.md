##1. 全链路工作台 🏗️

**分类**：平台类  
**优先级**：P0（核心卖点）

###一句话价值

从小说→剧本→分镜→漫剧，**一个工坊搞定**，不用切换5 个软件。

###详细说明

|项目 | 内容 |
|------|------|
| 用户痛点 |传统漫剧制作需在Word、PS、PR、AU等5+ 软件间切换，效率低、协作难 |
|我们的方案 |浏览器内一站式工作台，所有环节在一个 UI完成 |
|关键指标 |创作者学习成本从2 周降到2小时 |
| 上线状态 | ✅v1 已上线 |

###技术亮点

- 微前端架构，模块独立加载
-统一状态管理，跨模块数据无缝流转
-离线缓存，断网不丢数据

---

##2. AI智能拆稿 🎨

**分类**：生成类  
**优先级**：P0

###一句话价值

3 秒把小说章节拆成可拍摄的场景，**比人工快20 倍**。

###详细说明

|项目 | 内容 |
|------|------|
| 用户痛点 |3000 字章节人工拆稿要30分钟，新人拆不好 |
|我们的方案 | AI 基于LLM +规则引擎，3 秒输出场景树 |
|关键指标 |拆稿准确率95%，耗时<5 秒 |
| 上线状态 | ✅v1 已上线 |

###技术亮点

- 大模型：Qwen2.5-7B（本地部署）
-规则引擎：场景/角色/事件 三元组抽取
- 可手动调整，AI建议 +人工兜底

---

##3.角色一致性引擎 🎨

**分类**：生成类  
**优先级**：P0

###一句话价值

跨100帧保持角色脸/服装/声线稳定，**告别"换脸"翻车**。

###详细说明

|项目 | 内容 |
|------|------|
| 用户痛点 | AI 生成的角色，5帧后脸就变了，作品没法看 |
|我们的方案 | IP-Adapter +Reference Attention +声纹锁定 |
|关键指标 |100帧一致性95%+，失真率<5% |
| 上线状态 | ✅v1 已上线（待优化） |

###技术亮点

-角色立绘锁定：CLIP + LoRA 微调
-声纹锁定：Speaker Verification
-失真自动检测：人脸识别比对

---

##4. 多模态生成 🎨

**分类**：生成类  
**优先级**：P0

###一句话价值

文→图→视频→配音，**AI 全包**，一条龙出片。

###详细说明

|项目 | 内容 |
|------|------|
| 用户痛点 |传统流程要找画师/配音师/剪辑师，3-7 天才能出片 |
|我们的方案 |集成 ComfyUI + CosyVoice + FFmpeg，一条龙自动化 |
|关键指标 |45 秒漫剧22 秒生成，效率提升10 倍 |
| 上线状态 | ✅v1 已上线 |

###技术亮点

-图像：Stable Diffusion + ControlNet
-视频：AnimateDiff + SVD
-配音：CosyVoice +情感参数
-剪辑：FFmpeg +智能转场
