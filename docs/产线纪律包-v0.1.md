## §2 判例集（实测裁定，先例生效）

| # | 判例 | 结论 |
|---|------|------|
| P01 | 真人视频检测（7 组样本实测） | 卡"人脸可识别度"而非写实度：正脸清晰可辨=必拦；背影/侧后/过肩=放行；动画感=放行 |
| P02 | 单宫格分辨率上限 | 4K 切 3×3 单格仅 1365px（仅够 720p 竖屏）；1080p 竖屏最多切 2×2 |
| P03 | 静帧预演"没感觉" | 属常态：判断"成片感"必须动态样片；不辩解，直接跑单镜小样给他定性 |
| P04 | 火山烧钱史 | 多候选/整批提交→费用失控；对策：小样先行 + prompt/参数 hash 去重 + 预算熔断；仅钩子/转折/悬念镜允许多候选 |
| P05 | Agnes 一把梭 | 从未完整跑通；勿再推荐"单模型全流程"路线 |

## §3 双落盘一致性校验

**工具**：`check_dual_landing.py`（位于 Hermes 技能 `manhuaworks-project\scripts\`；只读、仅标准库）

```
python check_dual_landing.py
# 默认对比 桌面\千机工坊  ↔  D:\ManhuaWorks\docs
```

输出四类：① 只在桌面 ② 只在D盘 ③ **同名但内容不一致（需同步）** ④ 一致计数。
**纪律**：同名文件 md5 必须一致；新增/更新文档后跑一遍，**③ 清零才算收工**。
