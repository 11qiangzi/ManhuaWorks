## 使用说明

1. 真实用户的证言需获得**书面授权**（邮件/微信均可存档）
2. 头像/职位/公司需准确
3. 涉及具体数字的（如"节省 65% 成本"）需有数据支撑
4. 脱敏要求：客户公司名可用"某 MCN""某出版社"代替
5. 替换占位符 `<...>` 后才能上线

### 步骤 2：发起证言请求

**邮件模板**：

```
主题：聊聊你用 ManhuaWorks 的体验？（送 3 个月专业版）

[用户昵称] 您好，

看到您最近用 ManhuaWorks 做了 [作品名]，播放量 [XX]，
做得非常棒！

我们在做用户案例展示，想邀请您分享下使用体验：
1. 您是做什么的？
2. 用 ManhuaWorks 之前是怎么做的？
3. 用完之后有什么变化？（时间/成本/数据）
4. 最喜欢哪个功能？有什么建议？

时间 15-20 分钟即可，文字/语音/视频都行。

作为感谢：送您 3 个月专业版 + 5000 积分。

方便聊聊吗？

陈远枢
ManhuaWorks 运营总监
```

## 证言评分卡

发布前用这张表评估质量：

| 维度 | 满分 | 评分 |
|:--|:--|:--|
| **具体**（有数字、有对比）| 30 | /30 |
| **可信**（实名+职位+公司）| 20 | /20 |
| **相关**（目标用户关心）| 20 | /20 |
| **情感**（打动人）| 15 | /15 |
| **简洁**（< 100 字）| 10 | /10 |
| **可配图**（有视觉素材）| 5 | /5 |
| **总计** | 100 | /100 |

> **< 60 分不发，60-80 分修改后发，> 80 分直接发。**

## A/B 测试

落地页用 5 条证言，**随机展示 3 条**给不同访客，看哪 3 条的转化率最高。

测试周期：2 周
样本：> 1000 访客
决策：保留 Top 3 证言作为永久展示
