# 产线防呆底线(v0.1)· 每批开跑执行清单

> **定位**:千机工坊漫剧产线**每批生成**的"最小防呆集"——只收三类:官方规范硬规则、贵到不能犯的错、已定铁律。
> **用法**:开跑前过 ①,生成中守 ②,跑后过 ③,收批补 ④;四栏全部打勾,才允许放量、进入下一批。
> **关系**:不替代《官方标准执行方案》《Seedance导演手册》《参考素材体系v2》《导演工作法》——本清单是**执行闸门**,保证那些标准在每一批被真正执行。
> **缘起**:2026-09-28 立,先用于 P0《星种》批次;跑通后升级为《产线检查手册 v1.0》(按七阶段:S1素材→S2分镜→S3关键帧→S4视频→S5音画→S6合成→S7发布)。

## ① 开跑前 · 生成门(未过审 = 零调用)

- [ ] **本批提示词 + 参考素材已发梁总,并获明确批准**——未获批准,不调用任何生成模型(铁律)
- [ ] 涉及**剪辑/拼接**的操作,同样先批准、后执行
- [ ] 生成模式已确认:**A·融合首帧**(主推)或 **B·三图参考**;提示词形态与模式对应
- [ ] 素材逐件核对:提示词里每个引用(第N格 / 图片N / 素材名)都对应**真实存在**的文件
- [ ] 缺素材处已标 `⚠️待素材` 并汇总进《素材需求清单》——**不许拿近似图硬跑**
- [ ] 素材顺序/编号与提示词引用一一对应,宽高比与成片一致;参考人物 ≤4(用五件套配置时按官方序:脸→妆造→场景→运镜→音色)
- [ ] 提示词自检(最易踩的 5 条;全量对照《官方标准执行方案》§七):
  - [ ] 主体定义在开头,全程同一标签
  - [ ] 一镜一运镜;不写精确秒数
  - [ ] 情绪已外化成动作(不写"他很悲伤",写"低头、肩膀微颤、手指攥紧衣角")
  - [ ] 全局约束段在:实时速度/无变形/无闪烁/无字幕/无水印/无Logo
  - [ ] 符号规范:`{}`台词 `<>`音效 `()`BGM;提示词 ≤500 字
- [ ] 参数锁定:分辨率 / 比例 / 帧率 / 时长与本批规格一致;单条 ≤15s

## ② 生成中 · 钱袋纪律(烧钱环节)

- [ ] **小样先行**:新写法/新段型先跑 1-3 镜小样,梁总过目后才放量——绝不整批盲跑
- [ ] 提交前按 **prompt + 参数 hash 去重**——重复提交直接拦截
- [ ] 每镜生成前**报价**(净增量口径);多候选仅限钩子/转折/悬念镜,先便宜档挑、再成片档出
- [ ] 本批预算已报:预估 ¥____ ;熔断线 ¥____ ;全片预警 ≤150 元/集——超线即停、先报告

## ③ 跑后 · 验货门(不发废片)

- [ ] 每镜生成后**先自检、再谈放行**(成片段/帧同理):
  - [ ] 解剖/畸变(手、脸、物体变形)
  - [ ] 一致性:角色 ↔ 锚定图 / 场景 / 风格
  - [ ] 闪烁、跳帧、字幕水印残留
  - [ ] 运镜与戏相符(不是"能看就行")
- [ ] 不合格镜:**先列客观硬伤对照表**(姿态站桩/场景跑偏/构图摆拍/层次缺失)+ 修正方案,再交梁总——不空问"哪里不合格"
- [ ] 合格镜才打包发梁总;附:本镜消耗、累计消耗、余额
- [ ] 梁总反馈 → **当批判根因**(提示词/素材/参数/流程)→ 记入 ④
