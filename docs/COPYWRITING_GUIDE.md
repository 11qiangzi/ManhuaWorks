# 千机工坊 文案规范 (Copywriting Guide)

> 所有面向用户的文案必须引用 `@/config/naming` 中的常量，禁止硬编码。
> 本文档与 `D:\ManhuaWorks\apps\web\src\config\naming.ts` 保持同步。

---

## 1. 命名规则

### 1.1 品牌名

| 场景 | 正确 | 错误 |
|------|------|------|
| 产品名 | 千机工坊 | 漫工场 / ManhuaWorks / 千机 |
| 版权行 | 千机工坊 | 漫工场 · ManhuaWorks |

### 1.2 模块名 (MODULE_NAMES)

面向用户的模块名一律使用 `X生成器` 格式：

| 模块 key | 正式名 | 短名 | 图标 | 禁用旧名 |
|----------|--------|------|------|-----------|
| manga | 漫画生成器 | 漫画 | 🎨 | ~~漫改工坊~~ ~~千机·漫~~ |
| novel | 故事生成器 | 故事 | 📖 | ~~小说工坊~~ ~~千机·书~~ |
| promo | 宣传片生成器 | 宣传片 | 🎬 | ~~宣传片工坊~~ ~~千机·片~~ |
| adShort | 短视频生成器 | 短视频 | 📹 | ~~广告短片工坊~~ ~~千机·影~~ |
| adImage | 广告图生成器 | 广告图 | 🖼️ | ~~广告图工坊~~ ~~千机·图~~ |
| music | 配乐生成器 | 配乐 | 🎵 | ~~音乐工坊~~ ~~千机·曲~~ |

**引用方式：**

```typescript
import { MODULE_NAMES } from '@/config/naming'

// 正式名
MODULE_NAMES.manga.name  // "漫画生成器"

// 短名 (空间受限时)
MODULE_NAMES.manga.short // "漫画"

// 图标
MODULE_NAMES.manga.icon  // "🎨"
```

### 1.3 单位名 (UNIT_NAMES)

| 场景 | 正确 | 错误 |
|------|------|------|
| 生成次数 | 次 | ~~集~~ |
| 长文案 | 次生成机会 | ~~集数~~ |
| 剩余额度 | 今日剩余 | ~~今日余集~~ |

```typescript
import { UNIT_NAMES } from '@/config/naming'

UNIT_NAMES.quota      // "次"
UNIT_NAMES.quotaLong  // "次生成机会"
UNIT_NAMES.dailyQuota // "今日剩余"
```

### 1.4 功能名 (FEATURE_NAMES)

| 场景 | 正确 | 错误 |
|------|------|------|
| 自带密钥功能 | 自备密钥模式 | ~~BYOK~~ |
| 功能描述 | 用自己的AI账号，更省钱 | ~~Bring Your Own Key~~ |
| 平台收费 | 平台服务费 | ~~通道费~~ |

```typescript
import { FEATURE_NAMES } from '@/config/naming'

FEATURE_NAMES.byok         // "自备密钥模式"
FEATURE_NAMES.byokDesc     // "用自己的AI账号，更省钱"
FEATURE_NAMES.platformFee  // "平台服务费"
```

## 2. 系统消息模板 (MESSAGES)

所有系统提示消息引用 `MESSAGES` 常量，确保语气统一（口语化、有温度、不冷冰冰）。

### 2.1 额度用完

```typescript
MESSAGES.quotaEmpty(3, '漫画')
// "今天的免费次数用完了——你离漫画只差1次，升级后立刻继续"
```

**设计意图：** 不用"您的额度已用完"这种冷漠措辞，而是用"你离 XX 只差 N 次"制造紧迫感和动力。

### 2.2 生成失败

```typescript
MESSAGES.generateFailed('模型响应超时')
// "AI脑子转冒烟了，模型响应超时。30秒后再试一次？"
```

**设计意图：** 幽默化解挫败感，给出具体原因和重试时间。

### 2.3 空状态

```typescript
MESSAGES.emptyState('漫画')
// "还没有漫画作品，来创建你的第一个吧"
```

**设计意图：** 不用"暂无数据"，直接引导用户行动。

### 2.4 加载中

```typescript
MESSAGES.loading('漫画')
// "正在让AI漫画师开工，预计15秒..."
```

**设计意图：** 将 AI 拟人化，增加趣味性和等待耐心。

### 2.5 API Key 失效

```typescript
MESSAGES.apiKeyInvalid
// "你的密钥好像过期了，去对应平台后台看看？"
```

**设计意图：** 不说"401 Unauthorized"，用日常口吻引导排查。

## 7. 语气规范

### 原则

1. **用"你"不用"您"** — 亲切不卑微
2. **口语化** — 像朋友推荐，不像客服话术
3. **给方案不给问题** — 出错时告诉用户怎么办，不只是说出了什么问题
4. **具体不抽象** — "30秒后再试"而非"请稍后重试"
5. **幽默化解** — "AI脑子转冒烟了"而非"系统异常"

### 禁止用词

| 禁止 | 替代 |
|------|------|
| 暂无数据 | 具体空状态文案 |
| 系统错误 | 具体原因 + 解决方案 |
| 请稍后 | 具体时间（如"30秒后"） |
| 操作失败 | 说清楚失败的是什么 |
| 集 (作为单位) | 次 |
| BYOK | 自备密钥模式 |
| 通道费 | 平台服务费 |
| 漫工场 | 千机工坊 |
| 千机·X | X生成器 |
