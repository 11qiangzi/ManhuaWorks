# FAQ — 漫改工作流 10 问

> 合伙人/投资人最常问的 10 个问题。

---

## Q1. BYOK 是什么意思？数据安全吗？

**BYOK = Bring Your Own Key**。用户自带 OpenAI/Stability/Replicate 的 API Key，平台**不存**业务数据。

- Key 加密存于本地 Keychain（macOS）/ Credential Manager（Windows）
- 我们的 `services/ai-orchestrator` 仅代理调用，不落库任何 prompt/输出
- 审计日志：仅记录调用次数 + token 量，不含内容
- **不提供 Key 的用户**：走平台共享 Key 池（成本 +30%，用于试看）

## Q2. 支持多少种语言？多语言切换麻烦吗？

**12 种**：中（简/繁）、英、日、韩、西、法、德、俄、阿、越、泰、印尼。

切换点：
- **输入原文**：任意 12 种之一均可
- **字幕导出**：一次出 N 套（按目标平台定）
- **TTS 配音**：12 种全支持
- **口型同步**：中/英/日/韩 强，西/法/德/俄/阿 弱，越/泰/印尼 一般

**不麻烦**：Designer 在「Language」节点选一次，下游全链路跟随。

## Q3. 角色/场景怎么保证"风格一致"？

**3 道关**：

1. **参考图锚定**：上传 1 张参考图 → 提取 embedding → 后续所有镜头匹配（CLIP > 0.78）
2. **LoRA 微调**（可选）：用 5-10 张图微调一个轻量 LoRA（~50MB），一致性拉满
3. **后置 QA**：每镜头 CLIP 比对参考图，不通过自动重试 / 标红

**角色变脸怎么办**：
- 同一角色跨镜头：embedding 锁
- 跨集：preset 复用
- **新需求**：Pipeline 2 character-replace 直接换角色

## Q4. 能不能批量生成？比如一晚上出 10 集？

**能**，走 Pipeline 5 **episode-batch**。

- 输入：整本书 txt（50 万字内）
- 流程：章节切分 → 并发 3 路 novel-to-drama → 集间一致性检查 → 打包
- 预估：10 集 × 30 镜头 = 300 镜头，Standard 模式 ~10 小时（并发 3）
- 成本：~¥900（单集 ¥90 × 10）
- **断点续**：中断后从失败镜头继续，不重跑

并发上限可调（默认 3，付费版最高 10）。

---

## Q5. 生成失败怎么办？会从头重跑吗？

**不会**。3 道恢复：

1. **单镜头**：自动重试 3 次（指数退避），仍失败 → 跳过 + 标红
2. **整 pipeline**：保留已生成产物，下次从断点续
3. **整集**：`services/ai-orchestrator/jobs/{id}/` 完整快照 → 可手工指定从哪个 shot 重跑

标红镜头会进 **QA 池**，设计师可：
- 一键重跑
- 改提示词重跑
- 直接丢弃（用前一镜头延续）

## Q6. 一集成本多少？三档质量差在哪？

| 模式 | 单镜头 | 单集（30 镜头）| 主要差异 |
|------|-------|--------------|---------|
| **Draft** | ~¥0.5 | ~¥15 | SDXL-Turbo + AnimateDiff-Light，4 秒/镜头 |
| **Standard** | ~¥3 | ~¥90 | Flux-Dev + SVD-XT，10 秒/镜头 |
| **Cinematic** | ~¥10 | ~¥300 | Flux-Pro + Upscale + CogVideoX-5B，10 秒/镜头 |

**质量差异肉眼可见**：
- Draft：构图偶有崩坏，色块粗，但剧情能看懂
- Standard：商业漫改基础线，客户验收
- Cinematic：接近动画电影单帧

**推荐组合**：Draft 内部审 → Standard 出货。

## Q7. WorkflowDesignerView（创作者工作台）能干什么？给非技术用吗？

**W5 林染交付的 16 文件面板**，核心能力：

- 拖拽节点画布（5 阶段 12 类节点）
- 实时看 prompt / 角色库 / 风格 preset
- 一键 Run / Pause / Resume
- 失败镜头高亮 + 重跑按钮
- 导出包下载

**非技术可用性**：
- ✅ 设计师 / 内容运营 / 编剧 上手 30 分钟
- ⚠️ 调 prompt 模板 / 节点参数仍需基础认知
- **预设库**：保存好的 pipeline 模板，PM 可一键跑

## Q8. AI 生成的内容版权归谁？

**默认用户所有**。

- 平台不主张任何权利
- 商用授权清晰（无 GPL / CC 限制）
- 唯一例外：用户用了**带版权的风格 LoRA**（如"模仿某漫画家"），需自负侵权风险
- 平台提供"无版权风格"白名单（见 12 风格预设），默认走白名单

## Q9. 跟 Comify / 字节豆包 / 腾讯智影 比，差异在哪？

| 维度 | ManhuaWorks | 通用漫改工具 |
|------|------------|------------|
| **目标客群** | B 端（MCN/网文平台/IP 方） | C 端玩票 |
| **批量化** | 一晚上 10 集 | 单集为主 |
| **风格一致** | 角色 LoRA + preset | 难 |
| **多语言** | 12 种 + 口型同步 | 1-2 种 |
| **桥接** | 推抖音/小红书 API | 手动上传 |
| **可定制 pipeline** | ✅ 节点画布 | ❌ 固定流程 |

**一句话**：我们是 **toB 漫改工厂**，不是 toC 玩具。
