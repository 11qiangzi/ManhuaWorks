# 阶段 5 — 导出（Export）

> **关键问题**：怎么出成片给到下游？  
> **耗时**：1-2 分钟  
> **核心**：格式 + 字幕 + 多平台适配

---

## 输出格式

| 格式 | 用途 | 分辨率 | 码率 | 容器 |
|------|------|-------|------|------|
| **mp4** (H.264) | 通用上传、剪辑 | 1080p / 720p | 6 Mbps | .mp4 |
| **mp4** (H.265) | 高质量存档 | 4K / 1080p | 8 Mbps | .mp4 |
| **mov** (ProRes) | 专业剪辑/PR/FCP | 1080p / 4K | 147 Mbps | .mov |
| **字幕文件** | 外挂 | — | — | .srt / .ass / .vtt |
| **封面图** | 平台封面 | 1080×1920 (竖屏) | — | .jpg / .png |

---

## 多平台适配预设

| 平台 | 比例 | 分辨率 | 时长 | 备注 |
|------|------|-------|------|------|
| **抖音 / TikTok** | 9:16 | 1080×1920 | ≤60s | 强竖屏，第一帧 hook |
| **快手** | 9:16 | 1080×1920 | ≤60s | 同上 |
| **小红书** | 9:16 / 3:4 | 1080×1920 | ≤5min | 标题/封面强调 |
| **B 站** | 16:9 | 1920×1080 | ≤10min | 横屏，长尾 |
| **YouTube Shorts** | 9:16 | 1080×1920 | ≤60s | 同 TikTok |
| **微信视频号** | 9:16 | 1080×1920 | ≤60s | 同上 |
| **Twitter/X** | 16:9 / 1:1 | 1920×1080 | ≤140s | 灵活 |

自动适配逻辑：

- 源视频 16:9 → 竖屏平台：智能裁切（人脸居中）
- 源视频 9:16 → 横屏平台：补背景模糊
- 时长截断：从头取 ≤上限；提示"超长，建议分集"

---

## 字幕文件

**自动生成 3 套**：

- `.srt` — 通用，YouTube/B 站/小红书
- `.ass` — 高级样式（字体/位置/动效），剪辑/PR 用
- `.vtt` — Web 用（HTML5 `<track>`）

**多语言** 一次出 N 个文件，命名 `episode.zh-CN.srt` / `episode.en-US.srt` …

导出包（zip）：

```
  ├── ep-001.en-US.srt

```

## 决策点

```
导出目标？
├── 国内短视频 → 抖音/快手/小红书 9:16 包
├── 海外短视频 → TikTok/Shorts 9:16 + 英文配音
├── 长视频平台 → B 站/YouTube 16:9
├── 专业交付 → mov + ass 字幕
└── 全部 → zip 一锅出

字幕处理？
├── 烧死（不可关闭）→ 适合无字幕阅读习惯平台
├── 软字幕（可关闭）→ 适合 B 站/YouTube
└── 双版本 → zip 一份各一份
```

## 产出路径

- 默认：`services/ai-orchestrator/exports/{episode_id}_{ts}.zip`
- 桥接层上传：`packages/toonflow-bridge/` 推送到目标平台（抖音/小红书开放 API）
- 历史/检索：进 `apps/studio/` 创作者工作台的「Library」view

---

## 验收

导出自动跑：

1. 文件可正常打开（ffprobe）
2. 时长符合平台上限
3. 字幕断句无超长行
4. 封面图无黑边/人脸
5. 音画同步漂移 < 100ms

任意一项不过 → 标红 + 通知，不进 release。
