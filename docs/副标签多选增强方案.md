# 副标签多选增强方案（世界观类型）

> 关联：漫改功能 UX 改进报告 F-09 后续 / 用户确认"世界观类型保持单选"后的增强项
> 作者：UX 研究员（探真真）+ 迫事部合体
> 日期：2026-07-10
> 状态：设计方案（待评审排期）

---

## 1. 背景与问题

当前漫改「世界观类型」为**单选**（`selectedWorldview: ref('')`，StoryboardEditorView L467），配合「补充世界观描述」文本框（`customWorldviewText`）表达混合题材。实测与代码走查发现两个真实短板：

- **画风推荐只认主基调**：`recommendedStyleIds`（L480-482）仅取预设 `preset.recommendedStyles`，混合元素（如"赛博朋克+武侠"里武侠部分）无画风引导，AI 易画风漂移。
- **描述框无结构**：用户不知如何写 AI 才理解，多元素主次不分时 AI 顾此失彼、一致性差。

用户确认维持单选主基调，但希望"多元素混合世界背景"表达更直观、画风更可控。

## 2. 目标

- 在**不破坏单选主基调**的前提下，新增「副标签多选」，表达混合世界观的元素构成。
- 副标签驱动**画风推荐聚合**与 **prompt 多元素权重结构化**，提升混合题材画风一致性。
- 兼容现有草稿持久化、历史项目继承、分镜级世界观覆盖。

## 3. 数据模型

```ts
// 现状
const selectedWorldview = ref('')           // 单选主基调 id
const customWorldviewText = ref('')          // 自由文本

// 改为
interface WorldviewSelection {
  primary: string          // 主基调 preset id（决定画风推荐主方向）
  tags: string[]           // 副标签 preset id 列表（多选，表达混合元素）
}
const selectedWorldview = ref<WorldviewSelection>({ primary: '', tags: [] })
const customWorldviewText = ref('')
```

`worldviewPresets` 中每个预设增加 `isTag: boolean` 与可选 `tagGroup` 字段，区分"主基调卡"与"副标签 chip"；副标签可复用现有预设的 `contextHint` / `recommendedStyles`。

## 4. UI 设计

```
🌍 世界观类型
┌─────────────────────────────────────────┐
│ 主基调（单选，决定画风推荐）              │
│ [科幻] [武侠] [奇幻] [都市] [蒸汽朋克] ... │  ← 原单选卡片，保留
└─────────────────────────────────────────┘
┌─────────────────────────────────────────┐
│ 副元素标签（可多选，表达混合）            │
│ [✓魔法] [修真] [机甲] [末日] [宫廷] ...   │  ← 新增 chips 多选
└─────────────────────────────────────────┘
补充世界观描述（可选）：[__________________]
推荐画风：赛博朋克、武侠水墨、……（聚合）
```

- 主基调卡片：`@click="selectedWorldview.primary = wv.id"`（单选替换）
- 副标签 chip：`@click="toggleTag(wv.id)"`（toggle 进/出 `tags` 数组）
- 选中态：主基调用 `--selected`，副标签用 `✓` 前缀 + `--active`
- 键盘：主基调卡 `role=radio` + `aria-checked`；副标签 `role=checkbox` + `aria-checked`（无障碍）

## 5. Prompt 合并策略

```ts
const worldviewContext = computed(() => {
  const parts: string[] = []
  const primary = worldviewPresets.find(w => w.id === selectedWorldview.value.primary)
  if (primary?.contextHint) parts.push(`【主基调】${primary.contextHint}`)
  for (const tid of selectedWorldview.value.tags) {
    const t = worldviewPresets.find(w => w.id === tid)
    if (t?.contextHint) parts.push(`【元素】${t.contextHint}`)
  }
  if (customWorldviewText.value.trim()) parts.push(customWorldviewText.value.trim())
  return parts.join('。')   // 用"【主基调】/【元素】"显式分隔，给 AI 权重信号
})
```

注入点不变（角色 L2042/L3486、场景 L4155、分镜 L4491 等），但文本从"平铺"变为"带主从标记的结构化"。

## 6. 画风推荐聚合

```ts
const recommendedStyleIds = computed(() => {
  const primary = worldviewPresets.find(w => w.id === selectedWorldview.value.primary)
  const tagStyles = selectedWorldview.value.tags.flatMap(tid =>
    worldviewPresets.find(w => w.id === tid)?.recommendedStyles ?? [])
  return Array.from(new Set([...(primary?.recommendedStyles ?? []), ...tagStyles]))
})
```

主基调画风 + 副标签画风取并集去重，解决"混合元素无画风引导"问题。

## 7. 兼容性影响

| 影响面 | 现状 | 改造后 |
|---|---|---|
| 草稿持久化（L4734） | `selectedWorldview: selectedWorldview.value` | 序列化 `{primary, tags}` 对象，localStorage 兼容 |
| 历史继承（L4786） | `selectedWorldview.value = d.selectedWorldview` | 兼容旧单字符串（迁移：旧值→`{primary:旧值, tags:[]}`） |
| genre 自动映射（L4050） | `selectedWorldview.value = genreMap[genre]` | 改为 `selectedWorldview.value.primary = genreMap[genre]` |
| 分镜级世界观（L485-497） | `sbWorldviewMode` global/none/custom | 保留；custom 可叠加全局 tags 作为元素提示 |
| 类型检查 | `string` | `WorldviewSelection`，需同步改类型与所有引用点 |

## 8. 风险与缓解

- **回归风险（中）**：`selectedWorldview` 类型变更波及多处引用，需全量 grep 替换 + `vue-tsc` 验证。缓解：先做类型兼容迁移（旧字符串自动转对象），再分批替换。
- **AI 一致性仍非 100%**：结构化 prompt 降低漂移但不保证，需真出图 A/B 验证（依赖 AI 服务可用）。
- **UI 复杂度**：副标签区需控制数量（建议 ≤12 个常用预设），避免选择过载。

## 10. 决策记录

- 用户确认：世界观类型**保持单选主基调**，混合题材靠"主基调 + 补充描述 + 分镜 custom"三层机制表达（当前可用）。
- 本方案为**增强项**，解决画风推荐不认混合、描述无结构的短板，非必须立即执行。
- 若暂不上本方案，当前"单选 + 描述框"已覆盖绝大多数混合题材场景（研究员建议：收益/风险比最高的现状方案）。
