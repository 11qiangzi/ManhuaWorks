## 调用机制（异步）

```
POST https://api.atlascloud.ai/api/v1/model/generateVideo
  { "model": "<id>", "prompt": "...", "image": "<URL|Base64|asset://>", 
    "last_image": "<尾帧>", "duration": 5, "resolution": "720p", "ratio": "adaptive",
    "generate_audio": true }
→ data.id（任务 ID）
轮询 GET https://api.atlascloud.ai/api/v1/model/prediction/{id}
→ status: completed 后取 data.outputs[0]（MP4 URL）
```

## 对漫剧线关键能力

- **Reference-to-Video（R2V）**：角色一致性利器。Seedance 2.5 支持最多 **50 个多模态参考**（角色图/场景/音频/3D 白模）
- **首尾帧控制（i2v first+last frame）**：Seedance 2.5 / Wan / Kling 系
- 视频编辑/扩展：Kling O3 video-edit、Wan 2.7 video-edit、Seedance 2.5 局部重写
- 音频：Seedance 2.5 原生同轮生成音频（对白/音效/配乐）；独立音频线 16 个模型（MiniMax/Suno/ElevenLabs/xAI）
