## 🧠 教训

1. **C 端首页不暴露内部架构** (4 大后台、L 等级是给团队看的, 不该给用户)
2. **404 链接是大忌** — 任何死链都要清理
3. **示例作品是 C 端最有效的信任建设** — 比 "查看文档" 转化率高 10 倍
4. **删除 ≠ 隐藏** — 真不需要的就删, 别留死代码
5. **重启 vite 要清缓存** — 老 chunk hash 会 504
