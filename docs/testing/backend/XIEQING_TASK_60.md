| 服务 | 端点数 | 覆盖要求 |

| user-service | 8 | 注册/登录/信息/更新/删除/列表/搜索/权限 |

**每端点检查**: 状态码 → 响应体结构 → 响应时间 → 错误信息

### 任务2: 鉴权三元测试

对每个端点：
1. **带正确 Token** → 期望 200/201
2. **不带 Token** → 期望 401
3. **带错误/过期 Token** → 期望 401/403

### 任务3: 分页边界

1. page=0 → 期望 400 或 返回第1页
2. page=-1 → 期望 400
3. page=999999 → 期望 200 (空数组)
4. pageSize=0 → 期望 400
5. pageSize=-1 → 期望 400
6. pageSize=10000 → 期望 400 或 限值

### 任务4: 超时+断连模拟

1. 模拟慢查询 (故意 sleep 或大 offset)
2. 模拟 DB 断连 (如果可访问测试环境)
3. 记录超时时长 / 错误响应格式

### 任务5: Redis 缓存

1. 首次请求 → 200 (查DB)
2. 立即重复请求 → 200 (命中缓存, 更快)
3. 缓存失效后 → 200 (重新查DB)
4. 记录缓存穿透风险

### 任务6: 限流+日志

1. 连续高频请求同一端点 → 验证限流触发 (429)
2. 检查错误日志记录完整性
3. 日志级别是否正确 (info/warn/error)

### 任务7: WebSocket

1. WS 连接建立 (collab/socket.io)
2. 消息收发验证
3. 断连重连机制
4. 房间鉴权 (未授权加入他人房间)

### 任务8: 交叉点前端

1. 使用林染的前端 API 调用清单
2. 从后端日志/响应验证前端调用的接口
3. 标记前端调了但后端不支持/返回异常的接口
