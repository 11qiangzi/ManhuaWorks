## 九、教训

1. **Vite proxy localhost** — 解决了 Chrome sandbox 网络隔离导致的全站 DOWN 问题，5 分钟修，影响 4 个 app
2. **localStorage key 统一是关键** — router guard / api-client / LoginView 三处必须同一 key，否则 token 注了白注
3. **ops 双视图从零到完整** — 林染新建 2 个 view 共 18.5KB，骨架屏→真实数据布局，远超 "空壳" 修复
