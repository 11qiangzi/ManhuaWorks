## 🚨 铁律

- **你测的是交互，不是代码** — 用用户视角，不是开发者视角
- **所有发现必须有证据** — 截图/录屏，口头=不合格
- **错误状态都要覆盖** — 正常流 + Loading + Empty + Error + 边界
- **交叉验证后端** — 前端调用的接口都要记下响应状态码

## 📋 任务清单

### 任务1: 按钮全覆盖点击 (5 站全部按钮)

| 站点 | 页面数 | 检查内容 |
|------|:---:|------|
| Web 主站 | ~10 | 全部 CTA/导航/功能按钮 |
| Admin Portal | ~5 | 全部管理操作按钮 |
| Ops Portal | ~5 | 全部运营操作按钮 |
| User Portal | ~5 | 全部用户操作按钮 |
| Studio 工作台 | ~19 | 全部创作工具按钮 |

**每按钮检查**: 是否有点击反馈 → 是否跳转正确 → 禁用态是否正确 → 重复点击不崩溃

### 任务2: Modal/弹窗/Toast

1. **全部弹窗**: 打开 → 关闭 → 再打开 (不能残留/叠加)
2. **遮罩层**: 点击遮罩关闭 / ESC 关闭
3. **Toast**: 出现时间 / 是否自动消失 / 有无关闭按钮
4. **多层弹窗**: A弹窗里打开B弹窗，关闭B后A是否正常

### 任务3: 表单边界测试

1. **全部输入框**: 正常值 / 空值 / 超长 / 特殊字符 / SQL注入/ XSS
2. **验证规则**: 错误提示是否清晰 / 提交按钮在未填写时是否disabled
3. **密码字段**: 显示/隐藏切换 / 自动填充
4. **下拉/多选/日期**: 选项正确 / 默认值合理

### 任务4: Tab/下拉/链接/导航

1. **Tab 切换**: 内容是否正确 / 切换动画卡顿
2. **下拉菜单**: 展开/收起 / 选项点击 / 键盘导航
3. **导航栏**: 当前页高亮 / 面包屑正确 / 返回按钮
4. **焦点状态**: Tab 键遍历全站，焦点环是否可见

### 任务5: Loading/Empty/Error 三态

1. **Loading**: 模拟慢网 (DevTools → Network → Slow 3G)
2. **Empty**: 空数据页面展示
3. **Error**: 断接口后的错误页面 / 重试按钮

### 任务6: 键盘导航

1. **Tab**: 焦点流是否正确 (左→右, 上→下)
2. **Enter**: 表单提交 / 按钮触发
3. **Esc**: 弹窗关闭 / 下拉收起
4. **快捷键**: 如有快捷键功能，全部验证

### 任务7: 交叉查后端接口

1. 用 DevTools Network 面板记录每个页面调用的 API
2. 对照谢擎的 API 清单 (42 端点)
3. 记录: 接口 URL + 状态码 + 响应时间
4. 非 200 响应的接口重点标注
