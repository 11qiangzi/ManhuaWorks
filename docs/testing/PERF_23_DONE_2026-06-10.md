**关键发现**:
- 🔴 **首次冷启动 748ms (P50)**, 预热后降至 133ms — **差 5.6 倍**。根因: 首次请求触发 DB 连接池初始化 + JWT 远程验证缓存 miss

- 🟢 **预热后 P50=133ms, P95=155ms** — 性能可接受

FROM shots WHERE project_id = '27fde728-8259-4594-a3db-4d99bbb608bb' ORDER BY sort_index;
```

```
Index Scan using idx_shots_project on shots  (cost=0.14..8.16 rows=1 width=488)
  (actual time=0.004..0.005 rows=0 loops=1)
  Index Cond: (project_id = '...'::uuid)
