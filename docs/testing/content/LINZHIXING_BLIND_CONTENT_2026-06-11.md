## 🔴 P0 — 阻塞级问题

### P0-1: 货币符号与币种混乱

**位置**: Admin Portal → 计费管理 (/billing) 订单列表
**问题**: 同一 ¥ 符号同时用于 CNY 和 USD
- `¥358 USD` — ¥ 是人民币符号，后面却标 USD
- `¥274 USD` — 同上
- 正确应为: `$358 USD` 或 `¥358 CNY`

**影响**: 用户在计费页面看到金额无法区分币种，可能引发支付纠纷。

## 🟠 P1 — 严重影响体验

### P1-1: 繁简中文混用 (Studio vs 其他4站)

**位置**: Studio 工作台 (5175)
**问题**: Studio 使用繁体中文，其余4站使用简体中文
- Studio: `漫工場` / `創作工作台` (繁体)
- Web/Admin/Ops/User: `漫工场` / `创作工作台` (简体)

**影响**: 品牌名称不统一，用户体验割裂。"場" vs "场" 需要统一。

### P1-2: 登录页条款文本重复

**位置**: Web 主站 → 登录页 (/login)
**问题**: 同一段条款确认文本出现2次
1. 复选框: "我已阅读并同意《服务条款》与《隐私政策》"
2. 按钮下方: "登录即代表您同意我们的 服务条款 与 隐私政策"

**影响**: 冗余信息，用户可能困惑"到底需不需要勾选"。

### P1-3: 系统级中英混杂 — 状态码

**位置**: Admin/Ops/User 全部3个Portal
**问题**: 所有状态字段使用英文值，中文UI配英文数据
- Admin用户表: `active` / `disabled` / `pending`
- Ops用户表: `active` / `trial` / `paused` / `revoked`
- Billing订单: `pending` / `paid` / `failed` / `refunded`
- 发票状态: `issued` / `void`
- 项目状态: `draft` / `running` / `reviewing` / `published` / `archived` / `failed`

**影响**: 目标用户群体(中文创作者)阅读体验差。建议全部汉化。

### P1-4: 套餐名/产品名中英混杂

**位置**: Admin Portal → 用户管理 (/users)
**问题**: 套餐列显示英文 `PRO` / `FREE` / `STUDIO`，无中文
Billing页面产品名也有英文: `Credits 500` / `Credits 2000` / `API 额度包`

**影响**: 用户无法直观理解套餐含义。

### P1-5: 表格列头中英混杂

**位置**: Ops Portal → 用户管理 (/users)
**问题**: 列头 `provider` 使用英文，其余列头为中文
- `邮箱 | 用户名 | provider | 状态 | 积分 | 注册 | 操作`

**影响**: 不统一，provider 应译为"供应商"或"AI 提供商"。

### P1-6: Showcase 作品类型标签全英文

**位置**: Web 主站 → 作品展示 (/showcase)
**问题**: 3部作品类型标签全部英文
- `Modern Romance · AI Comedy`
- `Xianxia Adventure · Long Form`
- `Near-Future SciFi · First Arc`

**影响**: 中文网站面向中文用户，核心内容描述用英文不合适。
