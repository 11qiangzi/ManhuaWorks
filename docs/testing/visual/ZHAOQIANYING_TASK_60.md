**每视口每页检查**:
1. 布局错位/元素重叠
2. 内容溢出/被截断
3. 按钮/文字被遮挡
4. 横向滚动条 (不该有的)
5. 固定元素位置是否正确

### 任务2: 触摸目标验证 (移动端)

1. 375px / 390px 视口全部按钮
2. 触摸区域 ≥ 44×44px (Apple HIG 标准)
3. 不合格元素截图 + 标注尺寸

### 任务3: 图片响应式

1. 全部图片元素 6 视口对比
2. 变形 (拉伸/压缩比例失调)
3. 裁剪 (重要内容被裁掉)
4. 分辨率 (低分屏下模糊)

### 任务4: 滚动体验

1. 横向滚动必要性审查
2. 不应有横向滚动出现的情况
3. 纵向滚动是否流畅
4. `overflow: hidden` 是否误用了

### 任务5: 导航适配

| 视口 | 导航形式 | 检查 |
|------|------|------|
| 375/390 | 汉堡菜单 | 展开/收起/遮罩 |
| 768 | 折叠菜单 或 横向 | 全部链接可见 |
| 1024+ | 横向导航 | 全部链接可见 + 当前页高亮 |

### 任务6: 字体/对比度 (WCAG AA)

1. 文字色/背景色对比度 ≥ 4.5:1 (正常文字)
2. 大文字 (≥18px bold / ≥24px) 对比度 ≥ 3:1
3. 链接文字是否有下划线 (非悬停态)
4. 字体大小是否可读 (移动端 ≥ 14px)

### 任务7: 加载性能

1. 切换页面时的视觉抖动/闪烁
2. 切换视口时的布局突变 (CLS)
3. 大图加载的占位符
4. 操作响应卡顿 (> 100ms 肉眼可见)
